# VALNATIR Web

> **Productive AI. Governed Data.**  
> *Govern the conversation, not the channel.*

Official web platform for **VALNATIR**, the enterprise-grade conversational flight control platform for regulated customer communications.

## 🚀 Key Highlights

- **Bilingual Architecture:** English by default at root `/`, Spanish at `/es/`, with bidirectional session-preserving switcher.
- **Corporate Visual Identity:** Custom typography (`DIN Alternate Bold`), dual-arc vector Isotipo with `#185359` / `#4B145F` gradient ramp, and 60 FPS procedural particle canvas reel.
- **Enterprise & Regulatory Focus:** Designed for Chief Information Security Officers (CISO), Data Protection Officers (DPO), and Compliance Committees.
- **Compliance Frameworks:** Adherent to Spanish National Security Framework (**ENS Media**, RD 311/2022) and European **DORA** (EU 2022/2554).
- **Official Meta Solution Partner:** Integrated with WhatsApp Business Platform and secure ephemeral web rooms.
